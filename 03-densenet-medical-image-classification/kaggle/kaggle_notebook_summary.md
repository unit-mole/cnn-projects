# Kaggle Notebook Summary

The notebook implements:

- folder-based dataset discovery and audit;
- class-count and imbalance analysis;
- conservative image augmentation;
- DenseNet121 ImageNet transfer learning;
- frozen-backbone training and optional fine-tuning;
- class weighting;
- accuracy, precision, recall, F1, macro F1, weighted F1, ROC-AUC, and PR-AUC;
- confusion matrix, ROC, precision-recall, threshold analysis, and error review;
- optional Grad-CAM;
- export of the trained `.keras` model and deployment metadata.
