# Delivery Notes

This build contains two kinds of artifacts:

1. **GitHub/Pages assets:** source code, documentation, tests, workflow, web interface, `model.json`, and 24 browser weight shards.
2. **Offline training artifact:** the supplied `models/resnet50_cifar100.keras`, included only in the full-offline ZIP and excluded by `.gitignore` for normal Git tracking.

The intermediate `models/resnet50_cifar100_browser.h5` is generated by `scripts/export_model.py` and is not duplicated in the final packages. The browser-ready TensorFlow.js files are already included under `web/tfjs_model/`.

Validation completed during packaging:

- 9 lightweight unit tests passed.
- Python source compiled successfully.
- JavaScript syntax passed `node --check`.
- TensorFlow.js model topology and all 24 manifest shards were present and non-empty.
- The ordered TensorFlow.js weight byte stream matched the flattened HDF5 source arrays.
- The flattened browser model returned exactly the same probabilities as the supplied `.keras` model for the recorded equivalence test.

A final interactive browser smoke test should be performed locally with `python scripts/run_local_web_server.py` because this build environment did not include a TensorFlow.js browser runtime package.

## This ZIP variant

This GitHub-ready package omits the large single-file `.keras` artifact. The complete browser model remains included under `web/tfjs_model/`.
