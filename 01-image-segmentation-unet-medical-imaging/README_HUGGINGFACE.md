# Hugging Face Space Card Copy

Use the project `README.md` as the Space README because it already includes the required YAML metadata. The recommended short description is:

> Interactive U-Net segmentation demo trained on deterministic synthetic MRI-style images, with binary masks, overlays, probability maps, Dice/IoU context, and responsible-use limitations.

## Demo use

1. Select a safe synthetic example or upload a non-sensitive image.
2. Adjust the threshold if desired.
3. Generate the predicted mask.
4. Review the original, mask, overlay, probability map, and summary.
5. Optionally upload a matching reference mask to calculate Dice and IoU.

## Medical disclaimer

This project is an educational portfolio demonstration. It is not a diagnostic tool and must not be used with private patient data or for medical decisions.
