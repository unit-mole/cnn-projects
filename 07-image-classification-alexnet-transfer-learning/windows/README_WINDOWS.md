# Windows RTX workflow

1. Double-click `01_setup_environment.bat` once.
2. Double-click `02_start_notebook.bat` to use the notebook workflow.
3. Run the notebook cells from top to bottom.
4. Double-click `04_export_and_test_browser.bat` after training.

`03_run_full_experiment.bat` is the command-line alternative to the notebook.
